# Security Policy

## Purpose

SenseLab is an educational security-assessment laboratory.

The application is intentionally designed around simulated and controlled scenarios.

## Responsible Disclosure

If a security issue is discovered in SenseLab itself, please report it privately rather than publicly disclosing the issue before it can be investigated.

## Scope

Security issues affecting:

- application security
- authentication
- authorization
- dependency security
- secrets handling
- data exposure
- container configuration
- unsafe application behaviour

are relevant.

## Out of Scope

The following are not considered vulnerabilities in the project:

- Findings that exist only inside intentionally simulated training scenarios
- Educational vulnerability examples that are clearly documented as simulations
- Attempts to use SenseLab against unauthorized third-party systems

## Responsible Use

SenseLab must only be used for authorized security testing and educational purposes.

Do not use the project to access, scan, exploit or disrupt systems without explicit authorization.
